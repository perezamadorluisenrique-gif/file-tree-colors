# Changelog

The release workflow uses the section named after the version being released
as the release description, so every version needs one. `npm version <x.y.z>`
renames the `Unreleased` heading below to that version.

## 0.1.0

- First release: set a color on any file or folder from the file explorer menu or a command, with an editable palette, text and/or background colors, cascading to the items inside folders, colors that follow renames and moves, and a one-click import from File Color.
